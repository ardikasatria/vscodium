## Siapkan lingkungan

Setiap mata kuliah memakai kumpulan pustaka Python-nya sendiri:

| Lingkungan | Dipakai untuk |
| --- | --- |
| Data Science | Data Wrangling |
| Deep Learning | Deep Learning (PyTorch CPU) |
| Pergudangan Data | PostgreSQL praktikum + dbt |

- Lingkungan yang dipakai **Kelas Anda** sudah dicentang.
- Yang sudah terpasang dari aplikasi DSWorkbench lama langsung dipakai, tanpa
  mengunduh ulang.
- Pemasangan butuh internet, dapat dibatalkan, dan kemajuannya tampil di panel
  **DSWorkbench: Lingkungan**.
- Tidak butuh hak administrator. Di Windows, Python dipasang ke folder aplikasi
  bila belum ada; di macOS/Linux dipakai Python 3.12+ yang sudah ada.

Keadaan tiap lingkungan selalu terlihat di bilah samping DSWorkbench, bagian
**Status**.
