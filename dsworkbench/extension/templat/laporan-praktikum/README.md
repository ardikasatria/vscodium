# Laporan praktikum (LaTeX)

Templat DSWorkbench untuk laporan praktikum singkat.

- `main.tex` — seluruh isi laporan. Ganti identitas di bagian atas (`\matakuliah`,
  `\modul`, `\namamahasiswa`, `\nim`, `\kelas`, `\asisten`).
- `gambar/` — taruh gambar di sini, lalu panggil dengan `\includegraphics{nama-gambar}`.
- `build/` — hasil kompilasi (`build/main.pdf`); boleh dihapus kapan saja.

Kompilasi: buka `main.tex`, lalu **DSWorkbench: Menulis — Kompilasi**.
